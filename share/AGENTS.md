# このサンドボックスについて

macOS ホスト上の Linux VM で動いています。Xcode や macOS 専用の CLI は、ホストで
実行されるものがブリッジ越しに使えます。

## ホスト CLI

PATH 上のコマンドのいくつかは、macOS ホストで本物を実行する中継コマンドです。
**ホスト側で動かせるのは `host-cli list` に出るものだけ**です。

## 成果物の置き場

スクリーンショット・録画・調査メモなど、**残したいものは
`$IOS_DEV_SANDBOX_ARTIFACTS` 配下**に置いてください。`shots/` `notes/` のように
用途で分けて構いません。ディレクトリは自分で作ります。

ここに置いたものはサンドボックスを作り直しても残るので、一時ファイルは `/tmp` に
置いてください。

## git と GitHub

`git@github.com:...` のリモートは HTTPS へ透過的に書き換えられます。`git remote -v`
がプロジェクトの設定と違って https:// を表示しますが、正常です。直す必要はありません。

`gh` で書き込めるリポジトリは決まっていて、一覧は
`~/.config/ios-dev-sandbox/writable-repos` にあります。ここに無いものは読み取り
専用です。書き込む前に確認してください。
