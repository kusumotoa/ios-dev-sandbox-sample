# 追加のディレクトリを読ませる

サンドボックスから見えるのは、起動したプロジェクトのディレクトリだけです。他にも読ませたいものがあるときに設定します。別のリポジトリ（Android・backend など）でも、仕様書を置いたディレクトリでも構いません。

## 手順

1. clone した ios-dev-sandbox の `local/read-only-dirs.txt` に、読ませたいディレクトリの絶対パスを 1 行ずつ書きます。ディレクトリであれば何でも構いません。`#` で始まる行と空行は無視されます。

```
/Users/you/Develop/Android/my-android-repo
/Users/you/Develop/Backend/api-server
```

2. `ios-dev-sandbox apply` でサンドボックスを作り直します。

## 知っておくこと

- **マシン単位の設定で、全プロジェクトのサンドボックスに載ります。** 他の `local/*` と同じ流儀です。プロジェクトごとに分ける仕組みは無く、読み取り専用なので分ける必要もありません
- ホストと同じ絶対パスで、**常に読み取り専用**でマウントされます。コピーではないので、ホスト側の変更が常に見えます
- パスの追加・変更のたびに作り直しが要ります。マウントはサンドボックス作成時に固定されるためです。`ios-dev-sandbox status` の `read-only dirs:` に件数が出ます
- `local/` は gitignore されているので、チームには共有されません。参照先をチームに伝えたいなら `share/AGENTS.md` に書いてください
- `apply` で作り直しても会話履歴はホストに残ります。ただし**自動では再開しません**。続きからやるには、コンテナ内で claude なら `/resume` か `claude --continue`、codex なら `codex resume` を実行します
