# コミット署名

## 設定は要りません

ホスト側で `git config --global user.signingkey` と `commit.gpgsign` が設定済みなら、サンドボックス作成時に自動で有効になります。使える鍵が無い場合は署名を有効にせず、未署名のまま普通にコミットできます。

## なぜ要るか

PAT は push を認証するだけで、署名はしません。署名が無いとコミットは GitHub 上で Unverified のままです。

## 秘密鍵はサンドボックスに入りません

サンドボックス内の `gpg` は本物ではなく、ホストへ中継するだけの小さなコマンドです。git の `gpg.program` がこれを指しているので、署名のたびに、署名対象のコミットオブジェクトだけがホストへ送られ、署名だけが返ります。

ホスト側は受け取ったものがコミットかタグでなければ拒否するので、鍵が他のデータの署名に使われることもありません。

## 検証はホスト側で

`git log --show-signature` はサンドボックス内では使えません。署名の検証には公開鍵が要りますが、鍵一式はホストの GPG にあり、サンドボックスへ渡しているのは署名を作らせる中継だけだからです。

GitHub 上の Verified 表示で確認してください。
